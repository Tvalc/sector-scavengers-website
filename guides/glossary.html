Gameplay terms

Run loopThe repeatable flow of one game attempt from start to loss or victory.

Deck pressureThe level of tension created by draw order, energy limits, and encounter timing.

Meta progressionPersistent progression between runs that changes future strategy options.

Encounter spikeA sharp jump in difficulty that tests whether a deck can survive current state.

Vertical sliceA small but complete playable segment used to validate core gameplay quality.

Makko terms

Collection (Makko)A visual context container in Art Studio used to keep style consistency across assets.

Manifest (Makko)Asset package that maps character animation states for in-game use in Code Studio.

Plan Mode (Makko)Code Studio mode that maps tasks and dependencies before implementation.

Quick Actions (Makko)Prebuilt actions in Code Studio for common tasks like adding characters and assets.
